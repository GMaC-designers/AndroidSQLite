# Android SQLite Notes App

This repository is a fork of the Android SQLite Notes App example originally published by AndroidHive. It demonstrates a basic Android app that stores notes using SQLite.

## Original tutorial and attribution

- Tutorial: https://www.androidhive.info/2011/11/android-sqlite-database-tutorial/
- Original demo APK: http://download.androidhive.info/apk/sqlite-notes-app.apk
- Video demonstration: https://www.youtube.com/watch?v=4YxUtIkG_gc

Original tutorial and project materials belong to their respective authors. This repository should be treated as a learning/forked example, not as an entirely original implementation.

## What it demonstrates

- Basic Android application structure.
- SQLite-backed local note storage.
- A simple notes-app workflow.

Refer to the source code for the exact implementation and available operations.

## Getting started

1. Clone this repository.
2. Open it in Android Studio.
3. Allow the project to sync with a compatible Android build environment.
4. Build and run the app on an Android device or emulator.

The project may use an older Android build configuration, so a compatible environment or a separately tested Gradle/dependency upgrade may be needed.
